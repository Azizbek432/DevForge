# ⚡ DevForge Battle

A minimalist, high-performance, and lightweight multi-language platform designed to sharpen frontend development skills through 10 critical theoretical questions and 10 progressive practical projects. Built with absolute clean semantics, zero external framework overhead, and optimized for self-driven code literacy.

🚀 **Live Preview:** [https://dev-forge-battle.vercel.app/](https://dev-forge-battle.vercel.app/)

---

## 🎯 The Core Philosophy: "No AI Code, Just Self-Learning"

In the era of automated code generation, copying and pasting raw script ruins true problem-solving capabilities. This platform is forged to break that dependency.

- **The Rule:** You are prohibited from copy-pasting code blocks from AI models.
- **The Path:** When a roadblock occurs, look up raw documentation, watch instructional architecture videos on YouTube, leverage StackOverflow, and code every single line from scratch.

## ⚡ Key Technical Features

- **Zero Dependency Architecture:** Native vanilla HTML5, custom-compiled utility CSS, and native ES6+ JavaScript.
- **Dynamic Internationalization:** Fully decoupled, client-side 3-Language Dictionary system supporting **English, O'zbek, and Русский** instantaneously without browser refresh triggers.
- **Optimized Layout:** Strict vertical-column data visualization focusing heavily on modern, readable structural flow and high-contrast typography.
- **Comprehensive Evaluation Matrix:**
  - 10 core theoretical concepts structured across distinct interactive A/B/C/D input blocks.
  - 10 curated sequential development roadmaps detailing exact functional specifications for real-world widgets.
